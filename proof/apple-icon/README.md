# Apple icon proof — BEFORE main a8aeaca8 vs AFTER feat/ios-store-icon f9c604e3

BEFORE commit a8aeaca8a35c9e15ae62c57c4283dab4a72f4fbc (main); AFTER = f9c604e3 = main a1a86ded (identical tree; `git diff f9c604e3 a1a86ded` is empty — verified), the SVG-rendered icons. BEFORE = main a8aeaca8.
Bundles: `nsh package --target ios-simulator` and `nsh package --target macos` (both ad hoc signed, unsigned for distribution), built from one checkout per commit with `../nsh` at the NSH pin 8c78cfd6d8ffcef260728ad2503d43c3bc9e86bf; `nsh -V` = nsh 0.6.1 (8c78cfd); cargo 1.99.0 (5f94df478 2026-08-27, rustup toolchain 1.99.0). Build folders were ~/BuwizNsh/target-icon-before and ~/BuwizNsh/target-icon-after (fresh, empty at start; deleted after packaging — the disk filled to 1 GB free mid-task, and deletion was ordered anyway). macOS 26.6.2, iOS 26.5 simulators (iPhone 17 Pro, iPad Pro 13-inch M5). Safety variables on throughout (SIMCTL_CHILD_ for the sims), GOOGLE_* unset, no sign-in, nothing queued; apps stayed on their first screen.
The iOS icon in the installed bundles was verified against nsh.json's `ios` icon: the bundle's own AppIcon60x60@2x.png IS the white-tile whole-logo master (AFTER) / the blue rounded "e" (BEFORE) — this is the app's own icon, not the NshDev host's. Mac bundles are the packaged .app (`nsh package --target macos` finished without errors for both commits). Its Contents/Resources/AppIcon.icns is generated by the package step itself from nsh.json's `macos` icon PNG (nsh-cli package.rs `macos_icns`: sips scales the PNG into an iconset, iconutil packs it) — for AFTER that is assets/macos/icon-1024.png, the white rounded tile. Reproducing that exact conversion gives an icns of 834,787 bytes with ten representations: 16, 32, 64, 128, 256, 512, 1024 px (16/32/128/256/512 pt at 1x and 2x). The repo also carries assets/AppIcon.icns (718,918 bytes, same artwork) but the package step does not use it. The .app copies themselves were deleted in cleanup after the captures, so the icns evidence is this reproduction plus the rendered results in the Dock/Finder captures.
