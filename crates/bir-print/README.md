# bir-print

eBIRForms print and frozen-HTML rendering. The frozen form sheets live in `html-frozen/` inside this crate and are compiled in by `build.rs`.

Part of [buwiz-forms](https://github.com/hexuria/buwiz-forms), the eBIRForms desktop app and `bir` CLI. This crate is published so `cargo install bir` resolves; its API is not stable on its own.
