# bir-desktop

eBIRForms desktop application library. The shipped app executable is named `bir`; the cargo target is `bir-desktop` so it does not collide with the `bir` CLI. Small embedded copies of repo assets live in `embedded/`.

Part of [buwiz-forms](https://github.com/hexuria/buwiz-forms), the eBIRForms desktop app and `bir` CLI. This crate is published so `cargo install bir` resolves; its API is not stable on its own.
