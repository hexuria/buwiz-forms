6 · Templates stop typing the same thing every quarter

Last submission2551Q · 2026-Q1
⟶ save as
2551Q templateuser ticks the fields to keep: ATC lines, tax-rate election, sheets attached…
⟶ next filing
2551Q · 2026-Q2pre-filled from the template + the profile-year; every field still editable
Never in a templatethe taxpayer profile (name, TIN, RDO, address…) — it comes from the profile-year, once
Defaultno template until the user makes one
A template is a saved answer to "what did I put last time?", per form, per profile. Overridable, optional, and never a second copy of the profile.
New: a per-form template store keyed by (profile, form), shared across years, every field overridable. Pre-fill order: profile-year → template → typed. The taxpayer profile is never copied into the template.
