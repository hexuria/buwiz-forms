## Running it safely

- Scratch only: `EBIR_TEST_ENV=1 BIR_DATABASE_PATH=/tmp/... BIR_SFTP_DRY_RUN=1
  crates/bir-shell/target/debug/bir-shell`. Without `EBIR_TEST_ENV` a scratch DB
  asks the keychain for the live key — never allow it.
- `BIR_SHELL_START="tp=123456788;form=2551Q/2026/3;part=1;items=4-7"` (dev only)
  opens a screen at launch; also `view=`, `theme=`, `panel=`, `open=security`.
- The maintainer runs AeroSpace. Move test windows to empty workspace 9 at
  once (`aerospace move-node-to-workspace --window-id <id> 9`) and capture them
  with `screencapture -l <id>`; never pull a test window onto the focused
  workspace. The maintainer's own release bir-shell may be running: only kill
  `crates/bir-shell/target/debug/bir-shell`.
