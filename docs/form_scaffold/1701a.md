## Step-by-Step Instructions

### Step 1: Generate Savefile (Windows)

Open eBIRForms on Windows → select Form 1701A → fill minimum fields:
- TIN: `000-000-000-000`
- Name: `TEST TAXPAYER`
- RDO: `039`
- Period: current year
- Monetary fields: `1,000.00`
- Click **Save**

Copy the `.xml` file to `~/Downloads/forms/1701Av2018/`

### Step 2: Discover Sources

```bash
python3 .agent/skills/form-generator/scripts/discover_sources.py \
  ~/Downloads/forms/1701Av2018/
```

### Step 3: Parse Payload

```bash
python3 .agent/skills/form-generator/scripts/parse_payload.py \
  ~/Downloads/forms/1701Av2018/<SAVEFILE>.xml \
  .generated/1701a/
```

### Step 4: Generate Formtype Layout

```bash
python3 .scripts/generate_formtype.py \
  --input ~/Downloads/forms/1701Av2018/1701A Jan 2018 v5 with rates.pdf \
  --form-id 1701Av2018 \
  --title "Annual Income Tax Return for Individuals Earning Income PURELY from Business/Profession (8% Flat Rate or Who Are Exempt under Tax Reform)" \
  --detect-fields
```

### Step 5: Generate Typed Form

```bash
python3 .agent/skills/form-generator/scripts/generate_typed_form.py \
  .generated/1701a/analysis.json \
  --target-dir crates/bir-core/src/forms \
  --view-dir crates/bir-desktop/src/views \
  
```

### Step 6: Integration

1. Add to `crates/bir-core/src/forms/mod.rs`:
   ```rust
   pub mod form_1701a;
   pub mod form_1701a_xml;
   ```
   Add `FormDraft::Form1701A(Box<form_1701a::Form1701ADraft>)` variant.

2. Add to `crates/bir-core/src/forms/support_level.rs`:
   ```rust
   // In FILEABLE_FORM_CODES:
   "1701A"
   // In fileable_form_type_id():
   "1701A" => Some("1701Av2018"),
   ```

3. Add to `crates/bir-desktop/src/views/mod.rs`:
   ```rust
   pub mod form_1701a_view;
   ```

### Step 7: Validate

```bash
cargo build && cargo test --package bir-core
```
