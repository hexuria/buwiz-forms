## Step-by-Step Instructions

### Step 1: Generate Savefile (Windows)

Open eBIRForms on Windows → select Form 2000DST → fill minimum fields:
- TIN: `000-000-000-000`
- Name: `TEST TAXPAYER`
- RDO: `039`
- Period: current year
- Monetary fields: `1,000.00`
- Click **Save**

Copy the `.xml` file to `~/Downloads/forms/2000-DSTv2018/`

### Step 2: Discover Sources

```bash
python3 .agent/skills/form-generator/scripts/discover_sources.py \
  ~/Downloads/forms/2000-DSTv2018/
```

### Step 3: Parse Payload

```bash
python3 .agent/skills/form-generator/scripts/parse_payload.py \
  ~/Downloads/forms/2000-DSTv2018/<SAVEFILE>.xml \
  .generated/2000dst/
```

### Step 4: Generate Formtype Layout

```bash
python3 .scripts/generate_formtype.py \
  --input ~/Downloads/forms/2000-DSTv2018/2000-DST Jan 2018 final.pdf \
  --form-id 2000DSTv2018 \
  --title "Documentary Stamp Tax Declaration/Return" \
  --detect-fields
```

### Step 5: Generate Typed Form

```bash
python3 .agent/skills/form-generator/scripts/generate_typed_form.py \
  .generated/2000dst/analysis.json \
  --target-dir crates/bir-core/src/forms \
  --view-dir crates/bir-desktop/src/views \
  --efps .generated/2000dst/efps_fields.json
```

### Step 6: Integration

1. Add to `crates/bir-core/src/forms/mod.rs`:
   ```rust
   pub mod form_2000dst;
   pub mod form_2000dst_xml;
   ```
   Add `FormDraft::Form2000DST(Box<form_2000dst::Form2000DSTDraft>)` variant.

2. Add to `crates/bir-core/src/forms/support_level.rs`:
   ```rust
   // In FILEABLE_FORM_CODES:
   "2000DST"
   // In fileable_form_type_id():
   "2000DST" => Some("2000DSTv2018"),
   ```

3. Add to `crates/bir-desktop/src/views/mod.rs`:
   ```rust
   pub mod form_2000dst_view;
   ```

### Step 7: Validate

```bash
cargo build && cargo test --package bir-core
```
