## Step-by-Step Instructions

### Step 1: Generate Savefile (Windows)

Open eBIRForms on Windows → select Form 1602Q → fill minimum fields:
- TIN: `000-000-000-000`
- Name: `TEST TAXPAYER`
- RDO: `039`
- Period: current year
- Monetary fields: `1,000.00`
- Click **Save**

Copy the `.xml` file to `~/Downloads/forms/1602Qv2019/`

### Step 2: Discover Sources

```bash
python3 .agent/skills/form-generator/scripts/discover_sources.py \
  ~/Downloads/forms/1602Qv2019/
```

### Step 3: Parse Payload

```bash
python3 .agent/skills/form-generator/scripts/parse_payload.py \
  ~/Downloads/forms/1602Qv2019/<SAVEFILE>.xml \
  .generated/1602q/
```

### Step 4: Generate Formtype Layout

```bash
python3 .scripts/generate_formtype.py \
  --input ~/Downloads/forms/1602Qv2019/1602Q Jan 2019.pdf \
  --form-id 1602Qv2019 \
  --title "Quarterly Remittance Return of Final Taxes Withheld on Interest Paid on Deposits/Yield on Deposit Substitutes/Trusts/Etc. and Tax on Winnings by Government and Its Instrumentalities" \
  --detect-fields
```

### Step 5: Generate Typed Form

```bash
python3 .agent/skills/form-generator/scripts/generate_typed_form.py \
  .generated/1602q/analysis.json \
  --target-dir crates/bir-core/src/forms \
  --view-dir crates/bir-desktop/src/views \
  --efps .generated/1602q/efps_fields.json
```

### Step 6: Integration

1. Add to `crates/bir-core/src/forms/mod.rs`:
   ```rust
   pub mod form_1602q;
   pub mod form_1602q_xml;
   ```
   Add `FormDraft::Form1602Q(Box<form_1602q::Form1602QDraft>)` variant.

2. Add to `crates/bir-core/src/temporal/support_level.rs`:
   ```rust
   // In FILEABLE_FORM_CODES:
   "1602Q"
   // In fileable_form_type_id():
   "1602Q" => Some("1602Qv2019"),
   ```

3. Add to `crates/bir-desktop/src/views/mod.rs`:
   ```rust
   pub mod form_1602q_view;
   ```

### Step 7: Validate

```bash
cargo build && cargo test --package bir-core
```
