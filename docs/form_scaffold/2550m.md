## Computation Logic

```
Output VAT (sales × 12%) → Input VAT → Net VAT → Credits → Penalties → Total
```

## Notes

Monthly version of 2550Q. Filed for months NOT ending a quarter (months 1,2 / 4,5 / 7,8 / 10,11).

## Step-by-Step Instructions

### Step 1: Generate Savefile (Windows)

Open eBIRForms on Windows → select Form 2550M → fill minimum fields:
- TIN: `000-000-000-000`
- Name: `TEST TAXPAYER`
- RDO: `039`
- Period: current year
- Monetary fields: `1,000.00`
- Click **Save**

Copy the `.xml` file to `~/Downloads/forms/2550M/`

### Step 2: Discover Sources

```bash
python3 .agent/skills/form-generator/scripts/discover_sources.py \
  ~/Downloads/forms/2550M/
```

### Step 3: Parse Payload

```bash
python3 .agent/skills/form-generator/scripts/parse_payload.py \
  ~/Downloads/forms/2550M/<SAVEFILE>.xml \
  .generated/2550m/
```

### Step 4: Generate Formtype Layout

```bash
python3 .scripts/generate_formtype.py \
  --input ~/Downloads/forms/2550M/bir2550m.pdf \
  --form-id 2550Mv2018 \
  --title "Monthly Value-Added Tax Declaration" \
  --detect-fields
```

### Step 5: Generate Typed Form

```bash
python3 .agent/skills/form-generator/scripts/generate_typed_form.py \
  .generated/2550m/analysis.json \
  --target-dir crates/bir-core/src/forms \
  --view-dir crates/bir-desktop/src/views \
  --efps .generated/2550m/efps_fields.json
```

### Step 6: Integration

1. Add to `crates/bir-core/src/forms/mod.rs`:
   ```rust
   pub mod form_2550m;
   pub mod form_2550m_xml;
   ```
   Add `FormDraft::Form2550M(Box<form_2550m::Form2550MDraft>)` variant.

2. Add to `crates/bir-core/src/temporal/support_level.rs`:
   ```rust
   // In FILEABLE_FORM_CODES:
   "2550M"
   // In fileable_form_type_id():
   "2550M" => Some("2550Mv2018"),
   ```

3. Add to `crates/bir-desktop/src/views/mod.rs`:
   ```rust
   pub mod form_2550m_view;
   ```

### Step 7: Validate

```bash
cargo build && cargo test --package bir-core
```
