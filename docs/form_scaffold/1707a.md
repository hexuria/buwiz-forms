## Step-by-Step Instructions

### Step 1: Generate Savefile (Windows)

Open eBIRForms on Windows → select Form 1707A → fill minimum fields:
- TIN: `000-000-000-000`
- Name: `TEST TAXPAYER`
- RDO: `039`
- Period: current year
- Monetary fields: `1,000.00`
- Click **Save**

Copy the `.xml` file to `~/Downloads/forms/1707Av2021/`

### Step 2: Discover Sources

```bash
python3 .agent/skills/form-generator/scripts/discover_sources.py \
  ~/Downloads/forms/1707Av2021/
```

### Step 3: Parse Payload

```bash
python3 .agent/skills/form-generator/scripts/parse_payload.py \
  ~/Downloads/forms/1707Av2021/<SAVEFILE>.xml \
  .generated/1707a/
```

### Step 4: Generate Formtype Layout

```bash
python3 .scripts/generate_formtype.py \
  --input ~/Downloads/forms/1707Av2021/1707-A April 2021 ENCS.pdf \
  --form-id 1707Av2021 \
  --title "Capital Gains Tax Return for Onerous Transfer of Shares of Stock Not Traded Through the Local Stock Exchange" \
  --detect-fields
```

### Step 5: Generate Typed Form

```bash
python3 .agent/skills/form-generator/scripts/generate_typed_form.py \
  .generated/1707a/analysis.json \
  --target-dir crates/bir-core/src/forms \
  --view-dir crates/bir-desktop/src/views \
  
```

### Step 6: Integration

1. Add to `crates/bir-core/src/forms/mod.rs`:
   ```rust
   pub mod form_1707a;
   pub mod form_1707a_xml;
   ```
   Add `FormDraft::Form1707A(Box<form_1707a::Form1707ADraft>)` variant.

2. Add to `crates/bir-core/src/forms/support_level.rs`:
   ```rust
   // In FILEABLE_FORM_CODES:
   "1707A"
   // In fileable_form_type_id():
   "1707A" => Some("1707Av2021"),
   ```

3. Add to `crates/bir-desktop/src/views/mod.rs`:
   ```rust
   pub mod form_1707a_view;
   ```

### Step 7: Validate

```bash
cargo build && cargo test --package bir-core
```
