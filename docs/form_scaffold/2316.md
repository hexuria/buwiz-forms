
## Notes

Employer-issued certificate. Substitutes for 1700/1701A for employees with single employer and no other income.

## Step-by-Step Instructions

### Step 1: Generate Savefile (Windows)

Open eBIRForms on Windows → select Form 2316 → fill minimum fields:
- TIN: `000-000-000-000`
- Name: `TEST TAXPAYER`
- RDO: `039`
- Period: current year
- Monetary fields: `1,000.00`
- Click **Save**

Copy the `.xml` file to `~/Downloads/forms/2316v2021/`

### Step 2: Discover Sources

```bash
python3 .agent/skills/form-generator/scripts/discover_sources.py \
  ~/Downloads/forms/2316v2021/
```

### Step 3: Parse Payload

```bash
python3 .agent/skills/form-generator/scripts/parse_payload.py \
  ~/Downloads/forms/2316v2021/<SAVEFILE>.xml \
  .generated/2316/
```

### Step 4: Generate Formtype Layout

```bash
python3 .scripts/generate_formtype.py \
  --input ~/Downloads/forms/2316v2021/2316 Sep 2021 ENCS_Final_corrected.pdf \
  --form-id 2316v2021 \
  --title "Certificate of Compensation Payment/Tax Withheld" \
  --detect-fields
```

### Step 5: Generate Typed Form

```bash
python3 .agent/skills/form-generator/scripts/generate_typed_form.py \
  .generated/2316/analysis.json \
  --target-dir crates/bir-core/src/forms \
  --view-dir crates/bir-desktop/src/views \
  
```

### Step 6: Integration

1. Add to `crates/bir-core/src/forms/mod.rs`:
   ```rust
   pub mod form_2316;
   pub mod form_2316_xml;
   ```
   Add `FormDraft::Form2316(Box<form_2316::Form2316Draft>)` variant.

2. Add to `crates/bir-core/src/forms/support_level.rs`:
   ```rust
   // In FILEABLE_FORM_CODES:
   "2316"
   // In fileable_form_type_id():
   "2316" => Some("2316v2021"),
   ```

3. Add to `crates/bir-desktop/src/views/mod.rs`:
   ```rust
   pub mod form_2316_view;
   ```

### Step 7: Validate

```bash
cargo build && cargo test --package bir-core
```
