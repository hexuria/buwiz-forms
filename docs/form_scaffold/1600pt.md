## Step-by-Step Instructions

### Step 1: Generate Savefile (Windows)

Open eBIRForms on Windows → select Form 1600PT → fill minimum fields:
- TIN: `000-000-000-000`
- Name: `TEST TAXPAYER`
- RDO: `039`
- Period: current year
- Monetary fields: `1,000.00`
- Click **Save**

Copy the `.xml` file to `~/Downloads/forms/1600-PTv2018/`

### Step 2: Discover Sources

```bash
python3 .agent/skills/form-generator/scripts/discover_sources.py \
  ~/Downloads/forms/1600-PTv2018/
```

### Step 3: Parse Payload

```bash
python3 .agent/skills/form-generator/scripts/parse_payload.py \
  ~/Downloads/forms/1600-PTv2018/<SAVEFILE>.xml \
  .generated/1600pt/
```

### Step 4: Generate Formtype Layout

```bash
python3 .scripts/generate_formtype.py \
  --input ~/Downloads/forms/1600-PTv2018/1600-PT January 2018 ENCS final.pdf \
  --form-id 1600PTv2018 \
  --title "Monthly Remittance Return of Value-Added Tax and Other Percentage Taxes Withheld" \
  --detect-fields
```

### Step 5: Generate Typed Form

```bash
python3 .agent/skills/form-generator/scripts/generate_typed_form.py \
  .generated/1600pt/analysis.json \
  --target-dir crates/bir-core/src/forms \
  --view-dir crates/bir-desktop/src/views \
  
```

### Step 6: Integration

1. Add to `crates/bir-core/src/forms/mod.rs`:
   ```rust
   pub mod form_1600pt;
   pub mod form_1600pt_xml;
   ```
   Add `FormDraft::Form1600PT(Box<form_1600pt::Form1600PTDraft>)` variant.

2. Add to `crates/bir-core/src/forms/support_level.rs`:
   ```rust
   // In FILEABLE_FORM_CODES:
   "1600PT"
   // In fileable_form_type_id():
   "1600PT" => Some("1600PTv2018"),
   ```

3. Add to `crates/bir-desktop/src/views/mod.rs`:
   ```rust
   pub mod form_1600pt_view;
   ```

### Step 7: Validate

```bash
cargo build && cargo test --package bir-core
```
