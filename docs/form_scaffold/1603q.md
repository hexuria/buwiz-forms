## Step-by-Step Instructions

### Step 1: Generate Savefile (Windows)

Open eBIRForms on Windows → select Form 1603Q → fill minimum fields:
- TIN: `000-000-000-000`
- Name: `TEST TAXPAYER`
- RDO: `039`
- Period: current year
- Monetary fields: `1,000.00`
- Click **Save**

Copy the `.xml` file to `~/Downloads/forms/1603Qv2018/`

### Step 2: Discover Sources

```bash
python3 .agent/skills/form-generator/scripts/discover_sources.py \
  ~/Downloads/forms/1603Qv2018/
```

### Step 3: Parse Payload

```bash
python3 .agent/skills/form-generator/scripts/parse_payload.py \
  ~/Downloads/forms/1603Qv2018/<SAVEFILE>.xml \
  .generated/1603q/
```

### Step 4: Generate Formtype Layout

```bash
python3 .scripts/generate_formtype.py \
  --input ~/Downloads/forms/1603Qv2018/1603Q Jan 2018 final.pdf \
  --form-id 1603Qv2018 \
  --title "Quarterly Remittance Return of Final Taxes Withheld on Fringe Benefits Paid to Employees Other Than Rank and File" \
  --detect-fields
```

### Step 5: Generate Typed Form

```bash
python3 .agent/skills/form-generator/scripts/generate_typed_form.py \
  .generated/1603q/analysis.json \
  --target-dir crates/bir-core/src/forms \
  --view-dir crates/bir-desktop/src/views \
  --efps .generated/1603q/efps_fields.json
```

### Step 6: Integration

1. Add to `crates/bir-core/src/forms/mod.rs`:
   ```rust
   pub mod form_1603q;
   pub mod form_1603q_xml;
   ```
   Add `FormDraft::Form1603Q(Box<form_1603q::Form1603QDraft>)` variant.

2. Add to `crates/bir-core/src/forms/support_level.rs`:
   ```rust
   // In FILEABLE_FORM_CODES:
   "1603Q"
   // In fileable_form_type_id():
   "1603Q" => Some("1603Qv2018"),
   ```

3. Add to `crates/bir-desktop/src/views/mod.rs`:
   ```rust
   pub mod form_1603q_view;
   ```

### Step 7: Validate

```bash
cargo build && cargo test --package bir-core
```
