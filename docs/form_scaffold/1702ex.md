## Step-by-Step Instructions

### Step 1: Generate Savefile (Windows)

Open eBIRForms on Windows → select Form 1702EX → fill minimum fields:
- TIN: `000-000-000-000`
- Name: `TEST TAXPAYER`
- RDO: `039`
- Period: current year
- Monetary fields: `1,000.00`
- Click **Save**

Copy the `.xml` file to `~/Downloads/forms/1702EXv2018/`

### Step 2: Discover Sources

```bash
python3 .agent/skills/form-generator/scripts/discover_sources.py \
  ~/Downloads/forms/1702EXv2018/
```

### Step 3: Parse Payload

```bash
python3 .agent/skills/form-generator/scripts/parse_payload.py \
  ~/Downloads/forms/1702EXv2018/<SAVEFILE>.xml \
  .generated/1702ex/
```

### Step 4: Generate Formtype Layout

```bash
python3 .scripts/generate_formtype.py \
  --input ~/Downloads/forms/1702EXv2018/1702-EX Jan 2018 ENCS v2.pdf \
  --form-id 1702EXv2018 \
  --title "Annual Income Tax Return for Use Only by Corporation, Partnership and Other Non-Individual Taxpayer EXEMPT Under the Tax Code" \
  --detect-fields
```

### Step 5: Generate Typed Form

```bash
python3 .agent/skills/form-generator/scripts/generate_typed_form.py \
  .generated/1702ex/analysis.json \
  --target-dir crates/bir-core/src/forms \
  --view-dir crates/bir-desktop/src/views \
  --efps .generated/1702ex/efps_fields.json
```

### Step 6: Integration

1. Add to `crates/bir-core/src/forms/mod.rs`:
   ```rust
   pub mod form_1702ex;
   pub mod form_1702ex_xml;
   ```
   Add `FormDraft::Form1702EX(Box<form_1702ex::Form1702EXDraft>)` variant.

2. Add to `crates/bir-core/src/temporal/support_level.rs`:
   ```rust
   // In FILEABLE_FORM_CODES:
   "1702EX"
   // In fileable_form_type_id():
   "1702EX" => Some("1702EXv2018"),
   ```

3. Add to `crates/bir-desktop/src/views/mod.rs`:
   ```rust
   pub mod form_1702ex_view;
   ```

### Step 7: Validate

```bash
cargo build && cargo test --package bir-core
```
