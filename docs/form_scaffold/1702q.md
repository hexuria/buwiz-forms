## Computation Logic

```
Sales → Cost → Gross → Deductions → Net Taxable → RCIT (25%) or MCIT (2%) → Credits → Penalties → Total
```

## Notes

Structurally similar to 1702RT but quarterly. Three quarters only (Q1-Q3), annual filed on 1702RT/MX/EX.

## Step-by-Step Instructions

### Step 1: Generate Savefile (Windows)

Open eBIRForms on Windows → select Form 1702Q → fill minimum fields:
- TIN: `000-000-000-000`
- Name: `TEST TAXPAYER`
- RDO: `039`
- Period: current year
- Monetary fields: `1,000.00`
- Click **Save**

Copy the `.xml` file to `~/Downloads/forms/1702Qv2018/`

### Step 2: Discover Sources

```bash
python3 .agent/skills/form-generator/scripts/discover_sources.py \
  ~/Downloads/forms/1702Qv2018/
```

### Step 3: Parse Payload

```bash
python3 .agent/skills/form-generator/scripts/parse_payload.py \
  ~/Downloads/forms/1702Qv2018/<SAVEFILE>.xml \
  .generated/1702q/
```

### Step 4: Generate Formtype Layout

```bash
python3 .scripts/generate_formtype.py \
  --input ~/Downloads/forms/1702Qv2018/1702Q 2018ENCS final2.pdf \
  --form-id 1702Qv2018 \
  --title "Quarterly Income Tax Return for Corporations, Partnerships and Other Non-Individual Taxpayers" \
  --detect-fields
```

### Step 5: Generate Typed Form

```bash
python3 .agent/skills/form-generator/scripts/generate_typed_form.py \
  .generated/1702q/analysis.json \
  --target-dir crates/bir-core/src/forms \
  --view-dir crates/bir-desktop/src/views \
  --efps .generated/1702q/efps_fields.json
```

### Step 6: Integration

1. Add to `crates/bir-core/src/forms/mod.rs`:
   ```rust
   pub mod form_1702q;
   pub mod form_1702q_xml;
   ```
   Add `FormDraft::Form1702Q(Box<form_1702q::Form1702QDraft>)` variant.

2. Add to `crates/bir-core/src/temporal/support_level.rs`:
   ```rust
   // In FILEABLE_FORM_CODES:
   "1702Q"
   // In fileable_form_type_id():
   "1702Q" => Some("1702Qv2018"),
   ```

3. Add to `crates/bir-desktop/src/views/mod.rs`:
   ```rust
   pub mod form_1702q_view;
   ```

### Step 7: Validate

```bash
cargo build && cargo test --package bir-core
```
