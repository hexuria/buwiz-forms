## Step-by-Step Instructions

### Step 1: Generate Savefile (Windows)

Open eBIRForms on Windows → select Form 1601EQ → fill minimum fields:
- TIN: `000-000-000-000`
- Name: `TEST TAXPAYER`
- RDO: `039`
- Period: current year
- Monetary fields: `1,000.00`
- Click **Save**

Copy the `.xml` file to `~/Downloads/forms/1601EQv2019/`

### Step 2: Discover Sources

```bash
python3 .agent/skills/form-generator/scripts/discover_sources.py \
  ~/Downloads/forms/1601EQv2019/
```

### Step 3: Parse Payload

```bash
python3 .agent/skills/form-generator/scripts/parse_payload.py \
  ~/Downloads/forms/1601EQv2019/<SAVEFILE>.xml \
  .generated/1601eq/
```

### Step 4: Generate Formtype Layout

```bash
python3 .scripts/generate_formtype.py \
  --input ~/Downloads/forms/1601EQv2019/1601-EQ January 2019 ENCS final.pdf \
  --form-id 1601EQv2019 \
  --title "Quarterly Remittance Return of Creditable Income Taxes Withheld (Expanded)" \
  --detect-fields
```

### Step 5: Generate Typed Form

```bash
python3 .agent/skills/form-generator/scripts/generate_typed_form.py \
  .generated/1601eq/analysis.json \
  --target-dir crates/bir-core/src/forms \
  --view-dir crates/bir-desktop/src/views \
  --efps .generated/1601eq/efps_fields.json
```

### Step 6: Integration

1. Add to `crates/bir-core/src/forms/mod.rs`:
   ```rust
   pub mod form_1601eq;
   pub mod form_1601eq_xml;
   ```
   Add `FormDraft::Form1601EQ(Box<form_1601eq::Form1601EQDraft>)` variant.

2. Add to `crates/bir-core/src/temporal/support_level.rs`:
   ```rust
   // In FILEABLE_FORM_CODES:
   "1601EQ"
   // In fileable_form_type_id():
   "1601EQ" => Some("1601EQv2019"),
   ```

3. Add to `crates/bir-desktop/src/views/mod.rs`:
   ```rust
   pub mod form_1601eq_view;
   ```

### Step 7: Validate

```bash
cargo build && cargo test --package bir-core
```
