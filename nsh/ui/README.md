The UI kit: every nsh/base control wrapped once and styled from theme tokens. Screens import from `ui/index.ts`, never
from nsh/base. Gallery: `screens/base/KitPage.tsx` (palette "UI kit" in the app; `BasePreview.tsx` for the kit's tests); screenshots: `just nsh-shots kit`.
Files: text.tsx (Text, Line, Code, titles, Icon, Kbd, Spinner), buttons.tsx, press.tsx (PressCard, PressCell: a card or cell that is one press target), lists.tsx, status.tsx, choice.tsx, fields.tsx,
layers.tsx, shortcut.tsx (ShortcutRecorder: press the box, then the keys; see AGENTS.md F17 and F19); pure logic in mask.ts (masks, dates), logic.ts (avatars, chips, pick-list filters) and chords.ts (the recorder's chords and the halving that finds what the platform lets an app bind), each with a *.test.ts.
The recorder takes a chord ending in a letter, a digit, F1 to F20, the space bar, an arrow, Home, End, Page Up, Page Down, or the minus, equal, bracket, backslash, semicolon, quote, comma, period, slash or backtick key (`EXTRA_KEYS` in chords.ts: 28 beyond the 48 letters, digits and F1 to F12), with any of Ctrl, Alt, Shift, Cmd: 76 keys x 16 modifier sets = 1216 chords, bound in one `keymap.bind` while it listens. Escape (cancel), Tab (move on), Backspace and Delete (remove) are its own; Enter, Insert and F21 to F24 are not offered. It stops listening when the app is no longer the active one (`lifecycle()`: another app has the keys), as Escape stops it. The part knows keymap's spellings only; the stored words (`SPACE`, `LEFT`, `COMMA` ...) are the screen's (`lib/settings_model.ts`).
